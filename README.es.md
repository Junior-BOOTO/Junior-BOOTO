## Competencias ilustradas en los proyectos

- **Diseño pedagógico:** coherencia entre objetivos, tareas y evaluación, visible en las secuencias A1 y las progresiones.
- **Diferenciación:** bancos de palabras, modelos y producción autónoma con un objetivo común.
- **Documentación de asistentes:** misiones, instrucciones, ejemplos de solicitudes y limitaciones. La documentación en GitHub no sustituye un GPT utilizable en ChatGPT.
- **Python y datos:** scripts de automatización, API locales y análisis documentados; cada proyecto detalla sus pruebas, demostraciones y límites.

Los cuadernos reflejan un proceso de aprendizaje y no una afirmación de dominio técnico avanzado.
